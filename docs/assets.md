# Assets

## banner.png

Repo banner / GitHub social preview.

Original SVG/CSS in the LCARS visual idiom. Inspired by [louh/lcars](https://github.com/louh/lcars) (GPL-3.0). No code copied.

LCARS, Star Trek, and the referenced place-names (Vandor, D'Arsay, Morska, Proxima Centauri, Ovion, Altamid) are property of Paramount/CBS. Used here in the fan-creation tradition.

## sirens-deep.svg, sirens-deep.png

Mark for the `sirens-deep` deployment. `sirens-deep.svg` is the source, `sirens-deep.png` a 512px render for avatar surfaces.

Built as a sibling of the coilyco org marks. The ring, the S glyph, and the ink / mint / lilac palette are measured from those avatars rather than approximated, so the geometry matches: mint ring r 165.5 w 12, lilac ring r 153 w 13, S stroke w 21 with round caps and joins.

The whale emblem nods at DeepSeek, which `agent/sirens-deep.yaml` selects. It is not a trace of their mark. Theirs is a soft organic silhouette; this one is redrawn as a stepped, blocked polygon in the coilyco idiom, and only the gesture is shared - mass low and left, fluke thrown up and right, a single eye dot. The DeepSeek name and logo are property of DeepSeek.
