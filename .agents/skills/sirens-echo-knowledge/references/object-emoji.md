# Object emoji

An emoji here is for legibility, never for tone. It helps an eye find an item
in a wall of text. It is not personality, warmth, celebration, or emphasis.

## The rules

* **The emoji follows the object, never replaces it.** Write `Wood 🪵`, never
  `🪵`. A reader whose client does not render it, or who uses a screen reader,
  must lose nothing.
* **At most three in one reply.** One or two is the ordinary case. A reply that
  wants a fourth should be a list without emoji.
* **First mention only.** Repeating it on every later mention is the noise this
  is meant to avoid.
* **Objects only** - items, resources, creatures, places, tools. Status dots,
  verdict marks, arrows, faces, and celebration marks are refused by the style
  check and are never correct here.
* **No obvious emoji means none.** Write the object plainly. An approximate
  emoji is worse than none, because a reader decodes it rather than skimming it.

## The shape

`Wood 🪵`, `Wheat 🌾`, `Elk 🦌`, `Axe 🪓`, `House 🏠`. An object not shown here
takes the plain conventional emoji for that thing, or none.
